# Elso Labs — Homebrew tap

```
brew tap elsolabs/census
brew trust --cask elsolabs/census/census
brew install --cask census
```

All three lines. Without the middle one Homebrew stops with an "untrusted tap"
error.

## Elso Census

A full count of what's on your Mac.

- Every app with what it really costs — the bundle plus the data it keeps elsewhere
- Every developer tool, and which copy your shell actually runs
- Every browser profile, split by what happens if you remove it
- Everything left behind by apps that are gone

Nothing is removed until you say so, and everything goes to the Trash.

Requires macOS 14 or later. Universal. *Tested on Apple Silicon; the Intel
build has not been run on an Intel Mac yet.*

Free. [elsolabs.com/census](https://elsolabs.com/census)

---

One cask, no source. It's generated by the release script alongside the disk
image it names, so the version and checksum can't drift from the build.
