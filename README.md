# Elso Labs — Homebrew tap

```
brew tap elsolabs/census
brew install --cask census
```

## Elso Census

A full count of what's on your Mac. Every app with its real size — the bundle
and the caches, data and settings it keeps elsewhere — every developer tool and
which copy your shell actually runs, every browser profile, and everything left
behind by apps that are gone. Each with what it costs you and what happens if
you remove it.

Requires macOS 14 or later. Universal — Apple Silicon and Intel.
*Tested on Apple Silicon; the Intel build has not been run on an Intel Mac yet.*

Free to use. [elsolabs.com/census](https://elsolabs.com/census)

---

This repository holds one cask definition and no source code. The cask is
generated by the release script alongside the disk image it names, so its
version and checksum are written in the same operation as the build they
describe — they cannot drift apart.
